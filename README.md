# Tencent Cloud AI CAN DO IT Hackathon — Singapore 2026

Project built using Spec-Driven Development with [GitHub Spec Kit](https://github.com/github/spec-kit).

## Workflow

1. `/speckit.constitution` — establish project principles
2. `/speckit.specify` — write the feature specification
3. `/speckit.clarify` — (optional) resolve ambiguities
4. `/speckit.plan` — create the implementation plan
5. `/speckit.tasks` — generate actionable tasks
6. `/speckit.analyze` — (optional) cross-artifact consistency check
7. `/speckit.implement` — execute the tasks

Specs live in `specs/`, project memory in `.specify/memory/`, and agent commands in `.devin/commands/`.
